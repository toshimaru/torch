# AGENTS.md

## Project Structure

Entrypoint and unit tests: [src/main.rs](src/main.rs). CLI integration tests: [tests/cli.rs](tests/cli.rs), which run Cargo's built binary via `CARGO_BIN_EXE_torch`. Package metadata and dependencies: [Cargo.toml](Cargo.toml) (package `torch-cmd`, binary `torch`). CI: [.github/workflows](.github/workflows). Do not edit `target/` or generated `target/distrib` outputs manually.

## Commands

- **Build:** `cargo build`
- **Run:** `cargo run -- <paths...>`
- **Test (all):** `cargo test`
- **Test (CLI integration):** `cargo test --test cli`
- **Test (single):** `cargo test <test_name>`
- **Lint (as in CI):** `cargo clippy --all-targets -- -D warnings`
- **Format:** `cargo fmt` / check with `cargo fmt --all -- --check`

Unix CLI permission tests use `/etc/denied` and `/etc/passwd` and expect an unprivileged user. A restricted sandbox can change the OS error text and fail these assertions.

## Architecture

Single-file CLI tool (`src/main.rs`) that combines `mkdir -p` and `touch`. Given a path like `a/b/c.txt`, it creates intermediate directories then creates/touches the file. A path with a trailing separator (`/`, or `\` on Windows) is treated as a directory and created in full. Both files and directories have their access and modification times updated; existing file contents are preserved.

All supplied paths are processed even if one fails. Filesystem errors are printed to stderr, and the process exits with status 1 if any path fails. Successful operations produce no output.

Core functions: `mkdir_touch` (orchestrator; creates directories via `create_dir_all`), `touch` (creates file or updates timestamps).

Dependencies: `clap` (CLI parsing with derive), `filetime` (timestamp manipulation).

## Release & Distribution

Uses [cargo-dist](https://github.com/axodotdev/cargo-dist) for releases. Config in `dist-workspace.toml`; `.github/workflows/release.yml` is generated by cargo-dist, so make configuration changes at the source and regenerate it.

- Targets: macOS (aarch64, x86_64), Linux (aarch64, x86_64, musl), Windows (x86_64, aarch64)
- Installers: shell script, Homebrew ([toshimaru/homebrew-torch](https://github.com/toshimaru/homebrew-torch))
- CI: GitHub Actions, runs plan on PRs
- Test CI: builds and tests on Linux and Windows; checks formatting and Clippy on Linux
